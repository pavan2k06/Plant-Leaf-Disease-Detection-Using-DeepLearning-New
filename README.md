# 🌿 Plant Leaf Disease Detection Using Deep Learning

A deep-learning–based system that detects diseases from plant leaf images using **EfficientNetB4**, trained on the **PlantVillage Dataset**.  
This project helps farmers and agricultural researchers to identify plant diseases early and prevent crop loss.

---

## 🚀 Features

- Detects plant diseases from leaf images with **99% test accuracy**
- Built using **EfficientNetB4 Transfer Learning**
- Works on **38 different plant disease classes**
- Includes easy-to-use **Tkinter GUI**
- Real-time prediction with confidence scores
- Trained using **Google Colab (GPU accelerated)**

---

## 🧠 Technologies Used

- Python  
- TensorFlow / Keras  
- NumPy, Pandas  
- Matplotlib / Seaborn  
- OpenCV, PIL  
- Jupyter Notebook (Google Colab)  
- Tkinter for GUI
